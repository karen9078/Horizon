## [Darling: Run macOS Software on Linux](https://www.darlinghq.org/) ⭐️ 7.0/10

Darling, an open-source compatibility layer, enables running macOS software on Linux without hardware emulation, currently supporting x86_64 architecture. The project remains active with a dedicated community, though updates are infrequent. This project bridges the gap between macOS and Linux ecosystems, potentially allowing Linux users to run macOS-only applications. It represents a significant technical effort in compatibility layers, though it is not yet a mainstream solution. Darling consists of a Mach-O binary loader and a userspace kernel server (darlingserver) that implements macOS's Mach IPC, POSIX, and Darwin syscall interfaces on Linux. It reimplements Apple frameworks like Foundation, AppKit (based on Cocotron), CoreAudio, and CoreFoundation, but currently only targets x86_64, not ARM64.

hackernews · Bluestein · Aug 31, 22:53 · [Discussion](https://news.ycombinator.com/item?id=49515830)

**Background**: Darling is a free and open-source macOS compatibility layer for Linux, similar to Wine for Windows applications. It works by providing alternative implementations of macOS libraries and frameworks, allowing macOS binaries to run natively on Linux without emulation. The project is developed openly on GitHub and distributed under the GNU GPL license.

## [Graham Dumpleton Introduces Wrapture for Python Tracing and Testing](https://simonwillison.net/2026/Aug/31/introducing-wrapture/) ⭐️ 7.0/10

Graham Dumpleton, creator of wrapt and mod_wsgi, has released Wrapture, a Python library that extends wrapt's monkeypatching to enable tracing and testing. The project is only a few weeks old and includes OpenTelemetry support and a configuration-based tracing mechanism. Wrapture offers a novel approach to monkeypatching that combines tracing and testing, potentially serving as an alternative to unittest.mock. It could be valuable for Python developers who need to observe or override functions in code they don't control, and its agent-driven development may influence future open-source practices. Wrapture allows wrapping any function or method to trace all access or override return values. It includes a TOML-based configuration for adding tracing to existing projects, and supports OpenTelemetry export. The project was entirely written by an AI assistant under Dumpleton's direction, which he emphasizes was not 'vibe coding' but careful engineering.

rss · Simon Willison · Aug 31, 23:59

**Background**: Monkeypatching is a technique in Python where code is modified at runtime, often used for testing or adding instrumentation. wrapt is a popular library for this purpose, providing a robust way to wrap functions. Tracing involves recording the flow of data and execution through a program, which is essential for debugging and performance monitoring. OpenTelemetry is an open standard for observability, providing APIs and SDKs for tracing and metrics.
