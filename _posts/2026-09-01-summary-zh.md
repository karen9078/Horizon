## [Darling：在 Linux 上运行 macOS 软件](https://www.darlinghq.org/) ⭐️ 7.0/10

Darling 是一个开源兼容层，无需硬件模拟即可在 Linux 上运行 macOS 软件，目前支持 x86_64 架构。该项目仍活跃，拥有专门的社区，尽管更新不频繁。 该项目弥合了 macOS 与 Linux 生态系统之间的鸿沟，可能使 Linux 用户能够运行仅限 macOS 的应用程序。它代表了兼容层领域的重要技术努力，尽管尚未成为主流解决方案。 Darling 包含一个 Mach-O 二进制加载器和一个用户空间内核服务器（darlingserver），在 Linux 上实现 macOS 的 Mach IPC、POSIX 和 Darwin 系统调用接口。它重新实现了 Apple 框架，如 Foundation、AppKit（基于 Cocotron）、CoreAudio 和 CoreFoundation，但目前仅支持 x86_64，不支持 ARM64。

hackernews · Bluestein · 8月31日 22:53 · [社区讨论](https://news.ycombinator.com/item?id=49515830)

**背景**: Darling 是 Linux 上的免费开源 macOS 兼容层，类似于 Wine 对 Windows 应用程序的支持。它通过提供 macOS 库和框架的替代实现，使 macOS 二进制文件无需模拟即可在 Linux 上原生运行。该项目在 GitHub 上公开开发，并以 GNU GPL 许可证分发。

## [Graham Dumpleton 推出 Wrapture，用于 Python 追踪与测试](https://simonwillison.net/2026/Aug/31/introducing-wrapture/) ⭐️ 7.0/10

wrapt 和 mod_wsgi 的创建者 Graham Dumpleton 发布了 Wrapture，这是一个扩展了 wrapt 的 monkeypatching 功能以支持追踪和测试的 Python 库。该项目仅有几周历史，包含 OpenTelemetry 支持以及基于配置的追踪机制。 Wrapture 提供了一种新颖的 monkeypatching 方法，将追踪和测试结合起来，可能成为 unittest.mock 的替代方案。对于需要在无法控制的代码中观察或覆盖函数的 Python 开发者来说，它可能很有价值，而且其由 AI 代理驱动的开发方式可能会影响未来的开源实践。 Wrapture 允许包装任何函数或方法，以追踪所有访问或覆盖返回值。它包含基于 TOML 的配置，用于向现有项目添加追踪，并支持 OpenTelemetry 导出。该项目完全由 AI 助手在 Dumpleton 的指导下编写，他强调这不是“vibe coding”，而是精心工程。

rss · Simon Willison · 8月31日 23:59

**背景**: Monkeypatching 是 Python 中在运行时修改代码的技术，常用于测试或添加检测。wrapt 是实现此目的的流行库，提供了健壮的函数包装方式。追踪涉及记录数据流和程序执行流程，对于调试和性能监控至关重要。OpenTelemetry 是用于可观测性的开放标准，提供用于追踪和指标的 API 和 SDK。
