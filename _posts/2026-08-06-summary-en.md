## [Deno's Celld Brings Durable Objects to Self-Hosted Environments](https://github.com/denoland/celld) ⭐️ 8.0/10

Deno has released Celld, an open-source daemon that runs Cloudflare Workers and Durable Objects on your own machines. Each object is its own SQLite database, addressed by name and replicated to an S3-compatible bucket you own, with nodes coordinating through that bucket alone, without a control plane or consensus. This release is significant because it brings the durable object abstraction, previously exclusive to proprietary platforms like Cloudflare, to self-hosted environments. It enables developers to build stateful serverless applications with more control and portability, potentially impacting edge computing and distributed systems. Celld uses SQLite as the storage engine for each object and replicates to S3-compatible storage, eliminating the need for a central control plane or consensus protocol. This design simplifies coordination and makes the system highly portable, as it can work with any S3-compatible storage provider.

hackernews · calvinfo · Aug 5, 16:50 · [Discussion](https://news.ycombinator.com/item?id=49185430)

**Background**: Durable Objects are a serverless abstraction that provides strongly consistent, stateful storage for applications, often used for real-time collaboration, AI agents, and session management. Traditionally, this capability was tied to specific cloud providers, limiting portability and control. Celld addresses this by allowing developers to run the same abstraction on their own infrastructure, using SQLite for local state and S3-compatible storage for replication.
