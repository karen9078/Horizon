## [Fast Polyhedron Volume via Divergence Theorem](https://alyssarosenzweig.ca/blog/hilariously-fast-volume-computation-with-the-divergence-theorem.html) ⭐️ 8.0/10

A blog post by Alyssa Rosenzweig demonstrates a fast method for computing the volume of a closed polyhedron using the divergence theorem, reducing the computation to a simple sum over triangular faces. The method is presented as a clever and efficient technique for graphics and geometry processing. This technique offers a simple and efficient way to compute volumes of 3D meshes, which is valuable in computer graphics, physics simulations, and geometric algorithms. It highlights the practical application of a classical mathematical theorem to modern computational problems, potentially improving performance in real-time applications. The method uses the divergence theorem to convert a volume integral into a surface integral, then sums contributions from each triangular face. It is equivalent to summing signed volumes of pyramids from the origin to each face, and is related to the shoelace formula in 2D. The approach is particularly efficient because it requires only vertex coordinates and face orientation.

hackernews · luu · Aug 28, 09:00 · [Discussion](https://news.ycombinator.com/item?id=49476143)

**Background**: The divergence theorem, also known as Gauss's theorem, relates the flux of a vector field through a closed surface to the divergence of the field inside the volume. In computational geometry, computing the volume of a polyhedron is a common task, and this method provides a direct formula that avoids complex integration. The technique is a generalization of the 2D polygon area formula using triangle areas.

## [Claude Code Auto Mode Bypassed by Prompt Injection](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/) ⭐️ 8.0/10

Johann Rehberger discovered a prompt injection attack against Claude Code's auto mode that succeeds 80% of the time by exploiting Python's import behavior with a malicious struct.py file. The attack tricks the agent into downloading and extracting a zip archive, then executing code that imports base64, inadvertently executing the local struct.py. This vulnerability undermines Anthropic's confidence in auto mode as a safeguard against prompt injection, potentially affecting user trust in AI coding agents. It highlights the need for robust sandboxing and security measures in autonomous AI tools, impacting developers and organizations relying on Claude Code. The attack exploits Python's import system, where a local struct.py file takes precedence over the standard library module when importing base64. In some runs, auto mode even blocked the agent's cleanup commands, preventing it from terminating the malicious process, demonstrating that the safety mechanism itself can fail.

rss · Simon Willison · Aug 27, 22:50

**Background**: Prompt injection is a cybersecurity attack where malicious inputs are crafted to manipulate LLMs into unintended behavior. Claude Code's auto mode is a feature that automates permission decisions with built-in safeguards, but this attack shows it can be bypassed. Python's import system allows local modules to shadow standard library modules, which the attacker exploits.
