## [Quantization-Aware Healing: 4-bit model beats full-precision original](https://huggingface.co/blog/MultiverseComputingCAI/quantization-aware-healing) ⭐️ 8.0/10

Quantization-Aware Healing (QAH) is introduced, a method that produces a 4-bit quantized model outperforming its full-precision (bfloat16) counterpart. Applied to a GPT-OSS 120B model compressed to 60B parameters and quantized to MXFP4, it beats the original on 7 of 9 benchmarks. This is a significant advancement in model compression, showing that quantized models can not only match but exceed full-precision performance. It could enable deploying large models on resource-constrained devices with improved efficiency and accuracy, impacting AI deployment in production. QAH is agnostic to the compression method, requiring only logit-level access to the uncompressed teacher. However, gains have not been verified for other structural-compression approaches like layer pruning, SliceGPT, or low-rank decomposition.

rss · Hugging Face Blog · Aug 25, 11:39

**Background**: Quantization reduces model precision (e.g., from 32-bit floats to 4-bit integers) to cut memory and computational costs, but often degrades accuracy. Quantization-Aware Training (QAT) is a common technique to mitigate this by training with quantization in mind. QAH extends this idea by healing a compressed and quantized model using logits from the original, achieving performance gains beyond the original.

## [Vercel Launches Run SDK for Secure AI Agent Code Execution](https://vercel.com/blog/introducing-run) ⭐️ 8.0/10

Vercel has released the Run SDK, a JavaScript/TypeScript execution environment that runs untrusted code in a QuickJS sandbox within a worker thread, isolating it from the host application and network. It supports host functions for controlled access and includes native human-in-the-loop approval and authentication checkpoints that can pause and resume execution. This addresses a critical security gap in AI agent development, where executing generated code with eval can expose secrets and internal services. By providing a secure sandbox with explicit host function boundaries and approval mechanisms, it enables safer deployment of agents that interact with real applications, potentially becoming a standard practice in the industry. The Run SDK evaluates code in a fresh QuickJS context inside a worker thread, with no direct access to Node.js or the network. Host functions are regular functions exposed as globals, and calls cross the sandbox boundary via serialization; the SDK supports resuming interrupted runs by replaying the program while reusing recorded results of settled host function calls.

rss · Vercel Blog · Aug 25, 04:00

**Background**: AI agents often generate TypeScript programs to coordinate tools and process results, but executing such code with eval grants it the same privileges as the host application, including access to secrets and internal services. Sandboxing techniques like QuickJS, a small embeddable JavaScript engine, provide isolated execution environments. Human-in-the-loop approval is a common pattern in agent frameworks to pause execution for sensitive operations, as seen in OpenAI Agents SDK and Microsoft's agent framework.
