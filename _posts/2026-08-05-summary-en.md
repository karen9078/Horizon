Y Combinator has open-sourced QM, an MIT-licensed multiplayer agent harness that runs in Slack and on the web, released on July 31, 2026. It is the same harness YC uses internally across accounting, legal, events, and engineering, including building QM itself. This open-sourcing is significant because it provides startups and developers with a production-tested, permissively licensed framework for building multiplayer AI agents, potentially accelerating adoption and innovation in agent-based systems. QM features scoped memory, sandboxes, and the same identity following a user between Slack and web surfaces. It is designed for startups, with swappable coding agents, security postures, and rollout checks, as detailed in deployment guides.
