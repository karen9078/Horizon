## [Run 125B Qwen on 16GB Mac via SSD Streaming](https://github.com/carloslfu/slotstream) ⭐️ 8.0/10

Slotstream, a new tool, enables running the 125B-parameter Qwen3.8-Flash-Next 4-bit model on Macs with as little as 16GB RAM, achieving ~12 tok/s on a 48GB Mac. It uses expert-offloading and SSD streaming, built natively with MLX and Swift. This project addresses a major barrier to local LLM inference: memory limitations. By enabling large MoE models to run on consumer hardware, it could democratize access to state-of-the-art models and spur further innovation in memory-efficient inference techniques. The model is a Mixture-of-Experts (MoE) architecture, which allows only active experts to be loaded into memory while others are offloaded to SSD. The tool includes an auto-mode that balances memory usage and speed, and future work includes implementing MTP (Multi-Token Prediction) for speculative decoding.

hackernews · carloslfu · Sep 1, 16:42 · [Discussion](https://news.ycombinator.com/item?id=49524447)

**Background**: Large language models (LLMs) typically require massive amounts of memory, often exceeding what consumer hardware offers. Mixture-of-Experts (MoE) models contain many specialized sub-networks (experts), but only a few are active per token, enabling selective loading. SSD streaming leverages fast NVMe drives to swap data in and out of memory, effectively treating storage as an extension of RAM. MLX is Apple's array framework for machine learning on Apple silicon, optimized for unified memory architecture.
